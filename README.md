# SUPERME AI 🤖

SUPERME AI — AI chat, coding assistant and project build platform.

## Planned capabilities

- Uzbek-first AI chat
- Coding, debugging and project generation
- File/project workspace
- GitHub integration
- Automated tests
- GitHub Actions build pipeline
- Android/Web build artifacts
- Conversation history and memory
- Multi-model architecture
- Image and voice integrations

## Architecture

`User → SUPERME AI → Agent → Workspace → Tests → GitHub Actions → Build artifact`

API keys and secrets must be stored in environment variables or GitHub Secrets, never committed to the repository.
